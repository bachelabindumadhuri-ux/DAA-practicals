# DAA Practicals

A collection of Data Structures and Algorithms practical programs (C implementations).

Includes:
- Sorting: Bubble, Insertion, Merge, Quick, Selection, Heap
- Searching: Linear, Binary
- Factorial (iterative & recursive)
- Knapsack, Matrix Chain

Build: use `clang` or `gcc` to compile each `.c` file. Example:

```bash
cd "DAA practicals"
clang MergeSort.c -o MergeSort
./MergeSort
```
